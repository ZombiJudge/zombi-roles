Zombi Roles

Setup guide for the bot owner

This covers creating the Discord bot, installing the app, and publishing updates. For day-to-day use, see the Help page in the panel.

1. Create the Discord application

The application is the bot's identity. Use a separate one for testing, so a test copy never collides with the live one.

  1. Go to https://discord.com/developers/applications and click New Application.
  2. Click Bot, and turn on Server Members Intent. Leave the other two off. The bot needs this to read the member list.
  3. Click Installation, set Install Link to None, and save.
  4. Click Bot again, turn off Public Bot, and save. Now only you can invite it.

2. Invite the bot

  1. Click OAuth2, then find OAuth2 URL Generator.
  2. Under Scopes, tick bot and applications.commands.
  3. Under Bot Permissions, tick only Manage Roles.
  4. Open the generated link, choose your server, and click Authorize.

3. Place the bot's role

In Server Settings, then Roles, drag the bot's role above every role it should manage. Discord only lets a bot manage roles below its own. Keep it below roles it should never touch, such as moderators.

4. Create a role for /rolebatch

Create a role with no extra permissions, such as Zombi Operator, and give it to the people who may use the command. The Discord server's Members page is under People in Server Settings.

5. Install on the computer that runs it

  1. Download the latest Windows or Mac zip from the Releases page of the GitHub repo.
  2. Extract it to a permanent folder. Do not run it from inside the zip.
  3. Double-click Zombi Roles Launcher.
  4. Under Bot, click Reset Token and Copy, then paste it on the setup screen. To find the server ID, turn on Developer Mode under User Settings, then Developer, and right-click the server icon.
  5. Choose the role for /rolebatch when the panel asks.

Run one copy at a time. Two copies with the same token both try to answer slash commands. Resetting a token cancels the old one everywhere, so any other computer needs the new one.

Saved data lives outside the app folder, in %APPDATA%\Zombi Roles on Windows and ~/Library/Application Support/Zombi Roles on Mac. A new copy of the app on that computer reads the same token. Delete that folder to start fresh.

6. Publish an update

Updates are signed with a private key at ~/.zombi-roles/release-key.pem, created once with npm run release:key. Keep a safe backup. If it is lost, installed copies can't accept new updates and need a fresh install. Never share it or put it in git.

  1. Merge your changes to main.
  2. Raise the version in package.json, merge that, and update your local main.
  3. Run npm run release. This builds the Windows zip, the Mac zip, and the signed update files in dist.
  4. Publish them with the version tag, replacing the version below:
gh release create v1.0.1 dist/* --title "1.0.1" --notes "What changed"

The notes appear in the update pop-up, so write them in plain words.

Good to know

  • The app needs Node.js 24 or newer, and installs nothing else.
  • Developer commands: npm test, npm start, and npm run demo for 900 fake members.
  • The invite filter uses an endpoint Discord does not officially support. It may change without notice.
  • Windows shows Unknown Publisher because the app has no paid code signing certificate.
