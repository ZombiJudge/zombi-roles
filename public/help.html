Zombi Roles

How to use Zombi Roles

Zombi Roles adds or removes Discord roles for lots of members at once. You never need to type a command. Everything happens by double-clicking a file, using a page in your browser, or using a slash command in Discord.

Starting the app

  1. Open the Zombi Roles folder.
  2. Double-click Zombi Roles Launcher.
  3. The control panel opens in your browser.

It runs in the background, so closing the browser tab does not turn it off. To get back to the panel, double-click Zombi Roles Launcher again.

The first time on Windows

Windows may show a blue box saying it protected your PC, or a warning that says Unknown Publisher. This is normal for a small app like this one. Click More info, then Run anyway, or click Run.

The first time on a Mac

macOS may say it can't verify the file. Click Done, then right-click the file, choose Open, and click Open again. If there is no Open choice, go to System Settings, then Privacy & Security, and click Open Anyway. If it asks to control Terminal, click OK.

If it asks for Node.js

Zombi Roles needs a free program called Node.js. The download page opens by itself. Choose the LTS version, install it with the normal options, then double-click Zombi Roles Launcher again.

Turning it off

Click Shut down at the top of the panel, then confirm. The bot stops until you start it again. It also stops when the computer sleeps, restarts, or shuts down.

Restarting

If something seems stuck, go to Settings and click Restart. It won't restart during a batch. If Zombi Roles has already stopped, double-click Zombi Roles Launcher instead, because a browser tab can't start a program.

Running a batch in the panel

Step 1: Members

Choose one of these at the top right:

  • Member list: tick members. You can search by name, or enter an invite code or link to show who joined with it. Select all shown picks everyone showing. The invite filter is experimental, so it may sometimes stop working.
  • List of names: paste names, one per line, or add a .txt or .csv file. You can mix usernames and display names. Then click Check names.

If a name has no match, or two members share it, a pop-up says what to fix. Zombi Roles never guesses. You can fix the name, or continue with the names that matched.

Step 2: Roles

Tick roles to add and roles to remove. A role that the bot can't manage is listed under Roles the bot cannot manage.

Step 3: Preview

Check the counts and the list. Nothing has changed yet. If it looks right, click Confirm.

Step 4: Run

Zombi Roles makes about one change a second, so 300 changes takes about 5 minutes. Click Stop at any time. Finished changes stay in place, and you can click Resume later.

If something goes wrong

An error report lists any changes that did not work and why. Click Download errors (CSV) to keep a copy.

To reverse a batch, go to Past batches and click Undo. You see a preview first. Undo only reverses changes that worked. If you were told some results could not be saved, keep the error CSV. Under Past batches, you can choose that file to undo those changes too.

Using /rolebatch in Discord

You need the Discord role chosen in Settings, and Zombi Roles must be running.

  1. Type /rolebatch in your server and press Enter. Only you can see the replies.
  2. Pick members and roles from the menus, up to 25 of each, then click See preview. For a longer list, add a file with the file option, or use the panel.
  3. Check the preview, then click Confirm.

You can also fill in names, add_roles, and remove_roles yourself, with commas between entries.

Discord only lets the bot update its message for 15 minutes. For longer batches you get a direct message when it finishes. The panel shows progress the whole time.

Updates

When a new version is ready, a pop-up offers Update now. Your token, settings, and results are kept. If something looks wrong afterward, go to Settings and click Go back to the previous version.

Common problems

Discord says the application did not respond

Zombi Roles is not running. Double-click Zombi Roles Launcher.

The browser never opens

Restart the computer, then double-click Zombi Roles Launcher again. If it still does not open, ask whoever set it up for you.

The panel says Connection lost

Zombi Roles stopped, often because the computer went to sleep. Double-click Zombi Roles Launcher, and the page reconnects. If a batch was running, resume it from Past batches.

Discord rejected the bot token

The saved token no longer works. Ask whoever set up the bot for a new one, then paste it in Settings. Treat a token like a password, and never share it in a message.

Your data

Your token, settings, and results stay on this computer. Batch files are deleted automatically after the number of days set in Settings, 30 by default.
